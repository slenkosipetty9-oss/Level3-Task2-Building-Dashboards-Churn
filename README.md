# Level 3 - Task 2: Building Dashboards - Churn Analysis

This repository contains my submission for **Codveda Technologies Level 3 Task 2**.
The goal of this task was to analyze customer churn data and build interactive dashboards to identify key patterns.

## Dataset
- Customer churn data from a telecom company
- Key columns: State, Voice Mail Plan, International Plan, Minutes, Churn

## Dashboards Included

### 1. Churn by State
**Insight**: Shows the top 10 states with the highest churn rates. 
This helps identify geographic areas that need customer retention focus.

### 2. Churn by Voice Mail Plan  
**Insight**: Compares churn rate between customers with and without a Voice Mail Plan.
Shows if having voice mail impacts customer retention.

### 3. Average Minutes by Churn Status
**Insight**: Compares average Day, Evening, and Night minutes for churned vs non-churned customers.
Helps understand usage patterns of customers who leave.

### 4. Churn by International Plan
**Insight**: Compares churn rate between customers with and without an International Plan.
Identifies if international plan users churn more.

## Tools Used
- Microsoft Excel for data analysis and dashboard creation
- Pivot Tables and Charts
- Data Visualization
